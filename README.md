☕ Mr. Cafe – Restaurant Website



🌐 Live Demo: https://mr-cafe-migx.vercel.app/


📖 Description:
Mr. Cafe is a responsive and modern restaurant website built with React, React Router, and Tailwind CSS. It features a dynamic menu, interactive components, and smooth navigation, providing users a seamless browsing experience.

✨ Features:

📱 Responsive design for desktop and mobile

🍵 Menu categories: Coffee, Food, Drinks

🎨 Interactive components: Hero section, Reviews, Offers, Videos

📩 Contact form and footer with relevant info

🔄 Built with React Router for smooth navigation

🛠️ Technologies Used:

React.js ⚛️

React Router 🧭

Tailwind CSS 💨
